# Secret 폴더 구축

1. Github App의 비밀키 PEM파일을 secret 폴더에 넣되, 이름은 `github-app-secret.pem`으로 지정한다.

**발급 절차:**  
1. Github App 설정 페이지 이동
2. General 탭에서 하단 Private Key 섹션 이동 후 PEM 파일 발급
